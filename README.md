# rubik-cube

A Rubik's Cube by Three.js.

## Setup

The slideshow-mel show-runner protocol lives in a submodule at
`vendor/slideshow-mel` and is consumed as a `file:` dependency, so it must be
checked out before `npm install`:

```
git clone --recurse-submodules <repo>
# or, in an existing clone:
git submodule update --init
```
